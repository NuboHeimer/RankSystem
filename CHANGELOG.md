# Changelog - История изменений RankSystem

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- [Инструкция по установке и первичной настройке](/docs/INSTALLATION.md)
- История изменений проекта (текущий файл)
- Новая таблица **DailyStats** для хранения статистики за день
- Сохранение статистики потраченных коинов
- Получение периодов статистики (7 дней, 30 дней, 365 дней)
- Получение календарных периодов статистики (неделя/месяц/год)
- Функционал переноса данных из minichat

### Исправлено

- Кнопка Refresh в интерфейсе базы теперь работает корректно
- Поле фильтрации закрывается при смене фокуса
- Баг с запоминанием истории ников

### Изменено

- **[README.MD](./README.MD)** -- изменена структура и описания.
- Фильтрация внесена в заголовки таблицы.

## [0.10.1] - 2025-05-26

### Добавлено

- Функционал проверки и списания валюты при вызове экшенов.
- Сохранение истории изменений ников зрителей.

### Исправлено

- Учёт времени просмотра не пытается искать зрителей в пустом списке.
- Оптимизировал подключения к базе данных и блокировки.

### Изменено

- Обновление даты фоллова теперь берёт дату и время из миничата, в случае, если данные пришли из него.

## [0.10.0] - 2025-04-14

### Добавлено

- Функционал вывода топов зрителей по количеству сообщений, времени просмотра и накопленным коинам.

## [0.9.3] - 2025-03-21

### Исправлено

## [0.9.0] - 2025-03-05

### Добавлено

## [0.6.1] - 2025-02-22

### Исправлено

## [0.4.0] - 2025-02-21

- Функционал посчёта времени просмотра

### Изменено

## Формат версионирования

- **MAJOR.MINOR.PATCH**
- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность (обратно совместимо)
- **PATCH** - исправления багов (обратно совместимо)
