# RankSystem WPF - Система рангов для стриминга

## Описание

RankSystem WPF - это современная WPF версия системы рангов для стриминга, которая заменила устаревший Windows Forms интерфейс. Приложение предоставляет удобный и красивый интерфейс для управления базой данных пользователей стриминговых платформ.

## Особенности

### 🎨 Современный Material Design интерфейс

- Красивый и интуитивно понятный дизайн
- Адаптивная цветовая схема
- Современные элементы управления

### 📊 Удобная работа с данными

- DataGrid с возможностью редактирования прямо в ячейках
- Поиск по всем полям в реальном времени
- Сортировка по любому столбцу
- Фильтрация данных

### 🔧 Функциональность

- Добавление новых пользователей
- Редактирование существующих записей
- Очистка коинов всех пользователей
- Удаление базы данных
- Автоматическое обновление данных

### 🏗️ Архитектура

- MVVM паттерн для лучшей организации кода
- Привязка данных (Data Binding)
- События и команды
- Разделение логики и представления

## Установка и запуск

### Требования

- .NET 6.0 или выше
- Windows 10/11

### Компиляция

1. Убедитесь, что у вас установлен .NET 6.0 SDK
2. Откройте командную строку в папке проекта
3. Выполните команду:
   ```bash
   dotnet build
   ```

### Запуск

1. После успешной компиляции выполните:
   ```bash
   dotnet run
   ```
2. Или запустите скомпилированный exe файл из папки `bin/Debug/net6.0-windows/`

## Использование

### Основные функции

#### 🔍 Поиск пользователей

- Введите текст в поле поиска для фильтрации пользователей
- Поиск работает по всем полям: UUID, Сервис, ID пользователя, Имя пользователя

#### ➕ Добавление пользователя

- Нажмите кнопку "➕ Добавить" для создания новой записи
- Заполните необходимые поля
- Данные автоматически сохранятся в базе

#### ✏️ Редактирование

- Кликните дважды на ячейку для редактирования
- Изменения автоматически сохраняются при переходе к следующей ячейке

#### 🔄 Обновление данных

- Нажмите кнопку "🔄 Обновить" для перезагрузки данных из базы

#### 💰 Управление коинами

- Кнопка "💰 Очистить коины" - очищает коины у всех пользователей
- Подтверждение действия для предотвращения случайной очистки

#### 🗑️ Управление базой данных

- Кнопка "🗑️ Удалить БД" - полностью удаляет базу данных
- Требует подтверждения из-за критичности операции

### Структура данных

#### Пользователи (Users)

- **UUID** - уникальный идентификатор
- **Service** - платформа (twitch, kick, trovo, vkvideolive)
- **ServiceUserId** - ID пользователя на платформе
- **UserName** - отображаемое имя пользователя
- **WatchTime** - время просмотра в секундах
- **FollowDate** - дата подписки/фоллоу
- **MessageCount** - количество сообщений
- **Coins** - количество монет
- **GameWhenFollow** - игра, в которую играли при фоллоу

#### История имен (UserNameHistory)

- Отслеживает изменения имен пользователей
- Автоматически создается при изменении UserName

## Интеграция с Streamer.bot

### Методы для вызова из Streamer.bot

#### `OpenRankSystemEditor()`

Открывает WPF редактор системы рангов.

#### `Init()`

Инициализирует базу данных (вызывать при запуске).

#### `AddMessageCount()`

Добавляет +1 к счетчику сообщений пользователя.

#### `AddWatchTime()`

Добавляет время просмотра для списка пользователей.

#### `AddFollowDate()`

Записывает дату фоллоу пользователя.

#### `AddCoins()`

Добавляет монеты пользователю.

#### `GetMessageCount()`, `GetWatchTime()`, `GetFollowDate()`, `GetCoins()`

Получают соответствующие данные пользователя.

#### `GetTopViewers()`

Получает топ пользователей по выбранному критерию.

#### `TransferFromMiniChat()`

Переносит данные из Live.json в базу данных.

### Пример использования в Streamer.bot

```csharp
// Открыть редактор
CPH.ExecuteMethod("RankSystem", "OpenRankSystemEditor");

// Добавить сообщение
CPH.ExecuteMethod("RankSystem", "AddMessageCount");

// Получить количество монет
CPH.ExecuteMethod("RankSystem", "GetCoins");
long coins = CPH.GetArg<long>("coins");
```
