## 🎯 Обзор системы

RankSystem - это комплексная система для отслеживания активности пользователей на стриминговых платформах. Система автоматически собирает статистику по просмотрам, сообщениям, фолловам и начисляет внутреннюю валюту (коины).

## ✨ Возможности

### Функционал

- 💰 Начисление и списание внутренней валюты по любому триггеру
  - Включает в себя платные команды.
- 📊 Статистика просмотра
  - Запоминание даты фоллова
  - Запоминание категории стрима при фоллове
  - Отслеживание времени просмотра стримов
  - Подсчет сообщений пользователя
- 📈 Вывод статистики пользователя
  - личная статистика пользователя
  - просмотр статистики других пользователей
- 🏆 Рейтинги
  - топ за день/месяц/год
  - топ за 24 часа, семь дней, 365 дней
- 🔄 История изменений никнеймов
- 💻 Графический интерфейс для просмотра и управления данными
  - 📋 Просмотр и редактирование данных
  - ➕ Добавление новых пользователей
  - 🗑️ Удаление пользователей
  - 🔍 Фильтрация и поиск
  - 📊 Сортировка по любому столбцу

### 🌐 Поддержка функционала на платформах

При наличии соответствующих триггеров.
Легенда:

- ✅ -- поддерживается, работоспособность проверена.
- ⚠ -- поддерживается с ограничениями. Смотрите раздел примечаний.
- 🧪 -- тестируется.
- ⏳ -- запланировано. Может быть нереализуемо.
- ❌ -- не поддерживается или не планировалось к разработке.

### Примечания

Подсчёт времени просмотра на ютубе и Trovo затруднён, так как на этих площадках отсутствует список _текущих_ зрителей. Там есть список _активных_ зрителей за какой-то промежуток времени. Соответственно, зритель может быть неактивным, но всё ещё смотреть стрим, при этом отсутствуя в списке.
